A small release.
One new flag, one hang fixed, one bug that depended on where you lived, and a toolchain bump to clear advisories published since v0.5.0.
Nothing breaks.

## The releases, podcasts and courses tabs open

A channel record has listed all four playlist tabs since v0.5.0, but only one of them could be opened.
`ytb playlists` takes a kind now:

```sh
ytb playlists @RickAstleyYT --kind releases
ytb playlists @TED --kind podcasts
ytb playlists @TED --kind courses
```

Three things were in the way.
The tab parser didn't know `playlistRenderer`, which is the shape the releases and courses tabs use.
A podcast lockup was dropped because only `LOCKUP_CONTENT_TYPE_PLAYLIST` was accepted.
And the reader hardcoded `/playlists`.

Fixing the lockup check also fixes search, which now finds podcasts: `ytb search "How to Be a Better Human" --type playlist` returns the show.
A release row's date no longer ends up inside `channel_title`, and an album's url is the album rather than its first track.

Asking for a tab a channel doesn't have is an error, not a quiet read of the home page:

```
$ ytb playlists @NBA --kind courses
ERROR  This channel has no courses tab; it has: featured, playlists, posts, search, shorts, streams, videos.
exit 3
```

## A refused download fails instead of hanging

googlevideo serves the first range of a stream URL it wants a PO token for and answers 403 to every range after it.
`ytb download` used to sit at 1 MiB forever when that happened.
The first failed chunk cancelled the others, a cancelled worker dropped its result, and the download waited on a result that never came.

Every chunk now reports in, so the download returns the 403 at once.
For those videos, `--use-yt-dlp` is still the way to get the file.
A test serves one range, refuses the rest, and fails if the download doesn't error within 20 seconds.

## Timestamps are UTC

`time.Unix` and `time.UnixMicro` return the local zone.
So the same player response parsed to `+07:00` on one machine and `Z` on another.
`last_modified` and stream URL expiry are UTC now, wherever the tool runs.

## Toolchain

**Go 1.26.11** and **golang.org/x/net v0.63.0** are the toolchain, and `govulncheck` is clean at the tag.
Between v0.5.0 and this release, 14 standard-library advisories and 6 x/net advisories were published.
One x/net advisory was reachable through `goquery`'s HTML parser.
Nine lint findings, mostly dead code, are cleared, so CI is green again.

## Install

```sh
go install github.com/tamnd/ytb-cli/cmd/ytb@latest
```

Prebuilt archives for Linux, macOS, and Windows, plus Linux packages (deb, rpm, apk), an SBOM and checksums, are on the [release page](https://github.com/tamnd/ytb-cli/releases/tag/v0.6.0).
The container image is on GHCR:

```sh
docker run --rm ghcr.io/tamnd/ytb:0.6.0 video dQw4w9WgXcQ
```
